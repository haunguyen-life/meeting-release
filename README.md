# Meeting Interpreter: bản phát hành

Repo này chỉ chứa bản phát hành của Meeting Interpreter, không có mã nguồn.

- Tải bản mới nhất: [Releases → Latest](https://github.com/haunguyen-life/meeting-release/releases/latest), file `MeetingInterpreter.msi`.
- App tự kiểm tra cập nhật qua `latest.json` của bản mới nhất, nên repo này phải để **Public**.
- Release được đăng tự động bởi GitHub Actions của repo mã nguồn. Đừng sửa hay xoá file trong Release bằng tay.
